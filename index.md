Privacy Policy for AI Translator Assistant

AI Translator Assistant does not collect, store, or share any personal data.

The extension only processes text that the user explicitly selects. This processing is done locally using Chrome’s built-in AI capabilities. No data is sent to external servers.

We do not collect:

* Personal information
* Browsing history
* Location data
* Authentication data

We do not sell, transfer, or use user data for any purpose outside the core functionality of the extension.
